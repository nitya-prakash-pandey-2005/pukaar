## Verified fine
- **CAP 1.2:** validates against the official OASIS `CAP-v1.2.xsd` (with `xmlschema`): a unit sample, a sample with control characters (after the fix) and a live export from the running fake server (`/api/broadcast` → `/api/broadcast/cap`). Required alert elements (identifier, sender, sent, status, msgType, scope) and info elements (category, event, urgency, severity, certainty) are present in schema order; `sent` is `2026-11-10T18:30:19+05:30` (timezone, no fractions); status stays `Exercise`; `& < >` are escaped by ElementTree; served as an attachment.
- **SMS intake:** empty or spaces → 400; over 1000 characters truncated by the route; garbled text still makes an (unlocated) incident with the safe reply; LLM down → incident plus fallback reply; an SMS with GPS next to a voice caller merges into that incident (seen live: "2 callers").
- **Relay:** English callers get the dispatcher's exact words; LLM down → English; live callers hear it through `say()`, callers who hung up get a callback (seen: banner with the dispatch and the message, each with audio).
- **Review Focus 1–5** each has a passing test: landmark alias (`test_locate_by_landmark_alias`), same family merges (`test_dedup_merges_same_roof`, `test_dedup_same_locality_similar_landmark_far_gps`, `test_two_callers_same_roof_merge`), bad triage JSON keeps facts (`test_extract_facts_bad_json_keeps_previous`), invented advice/arrival time replaced (`test_guard_reply`, time-promise tests), dispatch after hang-up queues a callback (`test_dispatch_after_hangup_queues_callback`).
- **Safety:** reply order is reassurance → at most one approved instruction → one question; condition-specific guidance is offered before general lines; every approved KB line and every fallback line still passes the guard (`test_guard_keeps_every_approved_line_and_plain_questions`).
- **Gnani concurrency inside Pukaar:** broadcast TTS runs one language at a time, filler warm-up is sequential, callback audio is rendered only when played; no `gather` of Gnani calls. Overlap between features is only safe once the engine is synced (finding 1).
- **Fake mode end to end** (`docs/screenshots/final/`, 1440×900 and 390×844): scripted Tanglish call → critical 84, located "both · 90%", reply time 0.4 s; SMS; dispatch with ETA; message; callback banner; surge replay (0 tokens); broadcast with audio; noise-drill card; mobile Call and Control-room tabs and the incident sheet.
